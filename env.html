이것만 기억하세요

  1. 설치하라는 창이 뜨면 "이게 뭐고 왜 필요해?"라고 먼저 물어보고, 이해되면 승인합니다.
  2. 작업 폴더는 새로 하나 만들어 연결합니다. 학생 개인정보가 든 폴더는 연결하지 않습니다.
  3. 학교 PC는 보안 프로그램 때문에 설치가 막힐 수 있습니다. 개인 노트북을 권합니다.
  4. ②·③은 유료 구독이 필요합니다. 요금과 기능은 자주 바뀌니 시작할 때 공식 안내를 확인하세요.

② 첫날 해 볼 순서 (10분)
  1. Claude 데스크톱 앱을 설치하고 로그인합니다. (claude.ai/download)
  2. 바탕화면에 AI작업 폴더를 새로 만듭니다.
  3. Claude 앱에서 그 폴더를 연결합니다. (대화 화면에서 바로 연결할 수 있습니다)
  4. 폴더에 지난 학습지 하나를 넣고 아래처럼 말해 봅니다.
이 폴더에 있는 학습지를 읽고, 같은 형식으로 다음 차시 학습지 초안을 만들어 줘. 만들기 전에 나에게 필요한 정보를 먼저 물어봐.
③ 첫날 해 볼 순서 (30분)
  1. GitHub 가입: github.com (만든 웹 활동을 학생에게 링크로 주는 곳)
  2. Claude Code 설치: 공식 안내(설치 문서)를 따르거나, 아래 '설치 도우미 프롬프트'를 쓰세요.
  3. Git 설치: Windows는 git-scm.com에서 받습니다. 대부분 '다음'만 누르면 됩니다.
  4. ①에서 만든 HTML 파일 하나를 작업 폴더에 넣고 아래처럼 말해 봅니다.
이 폴더의 html 파일을 GitHub Pages로 배포해서 학생들이 링크로 열 수 있게 해 줘. 내가 직접 클릭해야 하는 단계가 있으면 하나씩 알려 줘.
설치 도우미 프롬프트 (막히면 이것부터)

무료 대화창(①)에 붙여 넣으면, 설치를 한 단계씩 같이 해 줍니다.

나는 컴퓨터에 익숙하지 않은 교사야. [Windows / Mac] 노트북에서 [Claude 앱에서 폴더 작업 / Claude Code / Codex]를 쓰려고 해. - 필요한 것을 한 번에 한 단계씩만 알려 줘. - 각 단계마다 "화면에 무엇이 보이면 성공인지" 알려 줘. - 내가 "다음"이라고 하면 다음 단계로 넘어가. - 오류가 나면 내가 화면 내용을 붙여 넣을 테니 해결 방법을 알려 줘.
