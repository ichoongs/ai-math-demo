① 대화로 만든다 · 무료로 바로

무료 AI 대화창에 붙여 넣고 [ ]만 바꾸세요. 결과가 나오면 정답·해설에서 틀린 곳이 없는지 꼭 확인하세요.

[과목] [단원]에 대한 OX 퀴즈 5문항을 HTML 파일 하나로 만들어 줘. - 문항마다 O, X 버튼을 두고, 누르면 바로 정답과 한 줄 해설이 나오게 해 줘. - 학생들이 자주 틀리는 내용(반례, 오개념)을 2문항 이상 넣어 줘. - 맨 아래에 점수와 '다시 풀기' 버튼을 둬. - 휴대폰에서도 잘 보이게 해 줘. - 수식은 x², f′(x)처럼 키보드로 쓸 수 있는 표기로 써 줘.

휴대폰에서도 됩니다. Claude·ChatGPT 앱에 붙여 넣으면, 앱에 따라 결과 화면에서 바로 열어 볼 수 있습니다. 안 열리면 컴퓨터에서 이어서 하세요.

탐구 도구도 같은 방식입니다. "슬라이더로 [매개변수]를 바꾸면 그래프가 바로 바뀌는 HTML을 만들어 줘."

② 결과물을 맡긴다 · 기준 파일 만들기

매번 긴 프롬프트를 쓰는 대신, 내 수업의 규칙을 파일 하나로 만들어 두고 작업할 때마다 먼저 읽히는 방식입니다. 아래 프롬프트로 시작해 보세요.

내 수업용 '수업 설계 지침' 파일을 같이 만들고 싶어. 나에게 한 번에 하나씩 질문해서 아래 내용을 채운 뒤, 마크다운 파일로 정리해 줘. 1. 과목, 학년, 학급 구성(성취 수준 분포) 2. 내 수업 철학 한두 문장 3. 수업 방식(판서, 태블릿, 활동지 등) 4. 학습지 형식(쪽수, 단 구성, 빈칸 방식, 문제 처리) 5. AI가 절대 하지 말아야 할 것

세특도 같은 원리입니다. 작성 규칙·어휘·점검표를 파일로 두고, 학생별 근거 파일에 있는 내용만으로 쓰게 합니다. 실명 대신 번호나 가명을 쓰고, 학교 지침을 먼저 확인하세요.

③ 파일·앱을 만든다 · 학생에게 링크로

①에서 만든 HTML을 학생들이 링크나 QR로 열게 하려면 Claude Code나 Codex에 이렇게 말합니다. 처음 설정은 준비물 안내를 보세요.

이 폴더의 html 파일을 GitHub Pages로 배포해서 학생들이 링크로 열 수 있게 해 줘. 내가 직접 클릭하거나 로그인해야 하는 단계가 있으면 하나씩 알려 줘.

꼭 지킬 세 가지

  • 개인정보: 학생 실명·성적은 AI에 넣지 않고, 공개 저장소에는 절대 올리지 않습니다.
  • 검토 책임: AI 결과는 초안입니다. 최종 판단은 교사가 합니다.
